The memory vocabulary: fact type (glyph + word, never colour alone), scope (bar height grows with breadth), and confidence (word by default, percentage only in technical surfaces).

```jsx
<MemoryBadge type="policy" />
<MemoryBadge type="exception" label="3 occurrences" />
<MemoryScope scope="genie" full />
<MemoryConfidence level="high" />
```

Never expose vector/embedding language. Memory uses the violet-silver accent, never gold.
