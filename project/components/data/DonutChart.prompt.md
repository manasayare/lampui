Composition of a small set, or a single value against a target. Small by default — never a hero donut.

```jsx
<DonutChart centerValue="94%" centerLabel="automated" data={[{value:94,color:'var(--dataviz-1)'},{value:6,color:'var(--dataviz-neutral-4)'}]} />
<DonutChart gauge max={100} centerValue="62%" centerLabel="cache" data={[{value:62}]} />
```
