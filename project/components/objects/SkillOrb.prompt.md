The Skill: a circle, always visually subordinate to Agent hexagons. Active Skills inherit the Agent's gold execution state; suggested and learned Skills are dashed violet.

```jsx
<SkillOrb name="Reconcile" glyph="rule" state="attached" label />
<SkillOrb name="Verify" glyph="fact_check" state="running" size="sm" />
```

Never larger than the Agent it belongs to. Circles never carry status fills — only border and an optional corner dot.
